## What it does

Phones expose the **raw measurements** behind GPS. This project uses them to compute position from first principles:

1. Parse raw GNSS logs into tidy tables.
2. Compute each satellite's position from ephemeris data.
3. Solve the receiver position with **iterative least squares**.
4. Export the path to CSV and **KML** for Google Earth.

The chart compares my solution with the phone's own fused location on a real drive — including the honest outliers before the solver converges.
