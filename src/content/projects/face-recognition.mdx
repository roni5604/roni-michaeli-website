## Goal

Detect and classify human emotions from facial expressions — **in real time**, from an ordinary webcam, through an interface anyone can use.

## Pipeline

1. **Dataset** — scripted download and preparation of a public facial-expression dataset.
2. **Model** — a convolutional neural network built with TensorFlow / Keras.
3. **Training & evaluation** — dedicated scripts with reproducible metrics.
4. **Application** — a PySide6 (Qt) desktop app with live detection that saves each session and the frames it classified correctly.
