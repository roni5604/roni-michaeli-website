## The idea

Word games in Hebrew are rare, and the good ones rarely respect the language. **Find the Word** connects neighbouring letters — horizontally, vertically or diagonally — on a board that grows level by level, from a gentle 3×3 up to a challenging 7×7.

## How it's built

The game is a single **Flutter** codebase that runs identically on iPhone, Android and the web. Every push to `main` runs analysis and tests, then publishes the web build automatically — so the public link is always the latest version.

Boards aren't hand-made. A generator places letters so that each board is **guaranteed to be solvable** against a curated Hebrew dictionary — the same dictionary that later became the open [hebrew-words-db](/projects/hebrew-words-db) dataset.

## Details that matter

- **Final letters done right.** Hebrew has five letters with a different form at the end of a word. The board always shows the regular form to avoid visual noise, and the engine converts to the final form in the found word.
- **A reason to come back.** Stars, coins, a daily hint bonus that grows over a week, and a shop for extra hints.
- **Zoe the detective dog** guides new players through an interactive tutorial with animated demos.
- **Full RTL and accessibility** across the interface, set in the Heebo typeface.

## Code first, AI-accelerated

I wrote the game's architecture and core logic myself, and worked with AI coding agents to speed up the rest — design docs first, then implementation, with static analysis and tests in CI keeping every change honest.
